# NEXUS AI // COMMAND CENTER

A custom Android System Launcher and call interceptor built with Kotlin and Jetpack Compose. Designed with high-performance 2D Canvas graphics to run seamlessly on low-memory Android devices without frame drops.

## Features
* **Custom Home Screen:** Fully replaces the standard Android UI.
* **Permissions Engine:** Holographic glassmorphism UI for granting system permissions.
* **Nexus Boost Launcher:** Visual 2D initialization sequence before launching target applications.
* **Voice AI & Call Interception:** Overtakes the default dialer to announce incoming calls.
