# NEXUS AI // COMMAND CENTER

An elite Custom Android System Launcher and security suite built with Kotlin and Jetpack Compose. Designed with high-performance 2D Canvas graphics to run seamlessly on low-memory Android devices without frame drops.

## Integrated Systems
* **Custom Home Screen:** Fully replaces the standard Android UI.
* **Nexus Boost Launcher:** Visual 2D initialization sequence optimizing system state before launching target applications (optimized for battle royales).
* **WireGuard VPN Tunnel:** Native VpnService integration for encrypted routing.
* **Dual-Password Vault:** Duress PIN system revealing decoy apps vs. master hidden apps.
* **Voice AI & Call Interception:** Overtakes the default dialer to announce incoming transmissions.
